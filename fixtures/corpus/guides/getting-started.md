Install, configure, verify.

- Install the package
  - With pnpm
  - With npm
- Configure a provider
  1. Pick a backend
  2. Point it at a folder
  3. Open the playground
- Verify

```bash
pnpm add @hmzisb/notion-docs-react
pnpm dev
```
