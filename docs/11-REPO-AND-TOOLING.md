## 4. Styling pipeline

- Source components use Tailwind utilities and shadcn variables only.
- `build:css` runs two Tailwind CLI builds:
  1. `styles.css`: `src/styles/styles.css` (`@import "tailwindcss/utilities" layer(utilities)` plus module-private variables and the few component rules that cannot be utilities: editor prose spacing, wrapped in `@scope (.docs-root)`), compiled against `src/**/*.tsx` so every used utility exists; no preflight (`@import "tailwindcss/preflight"` absent), no theme reset. This is the non-Tailwind-host fallback and also the always-imported component sheet for Tailwind hosts (rules that are not utilities).
  2. `theme.css`: generated by `scripts/gen-theme.ts` from a fresh `npx shadcn@latest init -b radix` output in a temp dir: copies the `:root` and `.dark` variable blocks, rewrites selectors to `.docs-root` and `.dark .docs-root, .dark.docs-root`, appends the sidebar fallback block from docs/06 §2.
- Tailwind hosts also add `@source "../node_modules/@hmzisb/notion-docs-react/dist"` so their build emits the module's utility classes (dedupe with the fallback sheet is fine: identical rules).
- Portals: Radix portals render outside `.docs-root`; every portal container gets `className="docs-root"` through the `container` prop or a `DocsPortalRoot` element mounted by `DocsProvider`, so variables and scoped styles apply.
- Only `.docs-root` and descendants are styled. Never `html`, `body`, bare tags, or `*`.

## 5. shadcn and Plate registry setup (`packages/react/components.json`)

```jsonc
{
  "style": "new-york", "rsc": false, "tsx": true,
  "tailwind": { "css": "src/styles/styles.css", "baseColor": "neutral", "cssVariables": true },
  "aliases": { "components": "@/components", "ui": "@/ui", "utils": "@/lib/utils", "lib": "@/lib", "hooks": "@/hooks" },
  "registries": { "@plate": "https://platejs.org/r/{name}.json" }
}
```

- `@/*` maps to `packages/react/src/*` in `tsconfig.json` `paths` and in tsup via `esbuild` alias; no `@/` import survives into `dist` (tsup resolves it).
- Plate UI items are added with `npx shadcn@latest add @plate/<item>` into `src/editor/ui` (set `aliases.ui` for the `@plate` registry to `@/editor/ui`); their imports of `@/components/ui/*` are redirected to the module's own primitives in `src/ui`.
- Radix engine: `npx shadcn@latest init -b radix`. Check with `npx shadcn@latest info` that `base` is `radix` before adding anything.
- Registry files are copied source: edit freely, keep a `REGISTRY-SYNC.md` listing item names and the registry changelog timestamp at copy time so updates can be merged later.

## 7. Smoke hosts

- `smoke/tailwind-host`: Vite + Tailwind v4, imports `@hmzisb/notion-docs-react/shell` + memory adapter from the built `dist` through `workspace:*` after `pnpm build`, defines shadcn variables, renders `DocsShell`; Playwright checks the tree renders and a page opens.
- `smoke/plain-host`: Vite without Tailwind, imports `styles.css` and `theme.css`, renders `PageTree` + `DocumentView`; Playwright checks layout (sidebar width 240, row height 28) and that no global styles leaked (a `<p>` outside `.docs-root` keeps the browser default margin).
